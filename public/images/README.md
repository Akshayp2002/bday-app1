# Birthday App Images

Place your photos directly inside this `public/images` folder.

The app expects two image files:

1. `birthday-girl.jpg` — Main birthday photo (shown as a polaroid-style card)
2. `memory.jpg` — A second favorite memory photo

## How to use your own images

1. Replace `birthday-girl.jpg` and `memory.jpg` in this folder with your own photos.
2. Make sure the filenames match exactly, OR update the image paths in `app/components/WishDashboard.js`.

## Supported formats

Next.js Image component supports `.jpg`, `.jpeg`, `.png`, `.webp`, `.gif`, and `.avif`.

## Tip

For best results, use portrait-oriented photos with similar aspect ratios (around 4:5).
